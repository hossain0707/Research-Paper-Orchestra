# Annotated workflow demonstration

**Status:** Illustrative text walkthrough. This is not a hosted executable demo, and there are no measured benchmark results in this example.

## Example starting request

> I am researching multimodal stress detection using EEG features and facial microexpressions. Prepare a scientific manuscript outline and a study plan. I have not yet collected a validated dataset. Target venue: a computer vision conference.

## What the workflow should do

| Stage | Example behavior | What it must not do |
| --- | --- | --- |
| Intake | note the absent dataset and unknown participant protocol | invent participants or accuracies |
| Outline | propose questions, baselines and evidence requirements | declare novelty already established |
| Plotting | specify ROC, ablation and calibration plots for **future** data | create a fake ROC curve |
| Literature | retrieve and verify relevant primary literature if tools allow | invent citations |
| Writing | draft introduction and methods **as proposals** | present proposed experiments as completed |
| Reviewing | flag missing data, consent/ethics if applicable, generalization and baselines | pronounce the draft submission-ready |

## Suggested invocation

Use the [private ChatGPT plugin](https://chatgpt.com/plugins/plugins_6afdebaa853c8191839123d371b75ea9) and enter the example request above. Attach real CSVs, manuscript and BibTeX to enable evidence-grounded plotting and citation work. The quality and actual deliverables depend on the connected tools and files.
